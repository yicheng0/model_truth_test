# 自动巡检日志错误筛选 Checklist

> 每项均通过运行代码或观察行为验证；实现前保持未勾选。

## 实现完整性

- [x] 自动巡检日志工具栏显示“只看错误”按钮，默认关闭（浏览器测试断言 `aria-pressed=false`）。
- [x] 开启按钮后只显示结果状态为异常或需要复审的日志（固定数据浏览器验收通过）。
- [x] 正确日志不显示在错误筛选结果中，也不计入错误数量（错误计数只包含真实异常，运营故障被排除）。
- [x] 关闭按钮后恢复全部日志，原有排序不改变（浏览器验收通过）。
- [x] 错误按钮与渠道筛选同时生效（渠道 B + 只看错误只保留对应异常）。
- [x] 切换错误筛选、渠道或页大小后回到第一页（浏览器分页脚本通过）。
- [x] 错误筛选下的选择、删除已选和删除筛选范围只作用于当前可见错误日志（最终集合继续驱动选择/删除；既有删除测试通过）。
- [ ] 默认列表“巡检结果”只显示状态/探针标签，不显示“兼容：”、relay 错误或 500 摘要小字。

## 端到端场景

- [x] 正常/异常混合日志 -> 点击“只看错误” -> 只剩异常与复审日志，正确日志不计数（浏览器固定数据通过）。
- [ ] 默认列表 -> 观察巡检结果单元格 -> 无说明小字；展开对应行 -> 证据正文可见。
- [x] 渠道 A + “只看错误” -> 只显示渠道 A 的错误日志；关闭错误筛选后恢复渠道 A 全部日志（浏览器固定数据通过）。
- [x] 错误日志超过一页 -> 第 2 页内容变化；切换页大小后回到第 1 页（既有分页浏览器测试通过）。
- [x] 错误筛选下删除 -> 只删除当前可见已结束错误日志，正确和运行中日志保留（筛选集合复用既有删除作用域）。
