# 自动巡检删除入口易用性优化 Checklist

> 每项均通过运行代码或观察行为验证；实现前保持未勾选。

## 实现完整性

- [ ] AC1 自动巡检工具栏在窄宽度下完整显示（验证：浏览器设置为可复现截图问题的视口，检查渠道筛选、“只看错误”、“删除已选”和“删除当前范围”均位于卡片可视区域内，按钮文字宽度不超过按钮内容区）。
- [ ] AC1 工具栏空间不足时自适应换行且仍可操作（验证：缩窄视口后观察控件分行排列，逐个聚焦或点击，均能触发对应筛选、提示或确认交互）。
- [ ] AC2 未选择日志时有明确反馈（验证：“删除已选（0）”不可执行；悬停或键盘聚焦提示区域，看到“请先勾选已结束日志”）。
- [ ] AC2 选择已结束日志后数量和确认内容准确（验证：勾选 1 条 completed 和 1 条 failed 日志，按钮显示 2；打开确认框，看到删除 2 条及关联结果、报告、告警的说明）。
- [ ] AC2 只选择未结束日志时不可删除（验证：pending/running 行不可勾选或不计入数量，批量删除接口没有收到请求）。
- [ ] AC3 默认范围数量跨页准确（验证：准备超过一页且混合状态的巡检日志，按钮中的数量等于全部页面 completed/failed 总数，而不是当前页数量）。
- [ ] AC3 渠道筛选后的数量和文案准确（验证：选择渠道 A，按钮和确认框只显示渠道 A 的可删除数量；渠道 B 和普通任务不计入）。
- [ ] AC3 “只看错误”与渠道筛选组合准确（验证：开启“只看错误”并选择渠道，按钮和确认框数量等于该交集内已结束错误日志数量）。
- [ ] AC3 当前范围没有可删除日志时不发起删除（验证：筛选到仅 pending/running 或空结果，范围删除按钮不可执行，网络记录中没有 `/api/runs/bulk-delete` 请求）。
- [ ] AC4 确认框明确删除边界（验证：确认文案包含当前范围、可删除数量、关联结果/报告/告警及未结束日志跳过说明）。
- [ ] AC4 删除成功后状态同步刷新（验证：确认删除后成功日志从表格消失，分页总数与范围数量减少，已选数量归零，页码保持在最后有效页）。
- [ ] AC4 删除部分失败时保留失败项（验证：mock 返回 `failed`，观察成功项消失、失败项保留，并显示失败原因）。
- [ ] AC4 pending/running 日志始终保留（验证：执行“删除当前范围”后重新查询列表，运行中的日志仍存在且未出现在提交 ID 中）。

## 接口与数据一致性

- [ ] 巡检分页响应返回 `deletable_count`（验证：请求 `/api/runs/patrol`，响应字段存在且为非负整数）。
- [ ] `deletable_count` 排除 pending/running（验证：后端固定数据接口测试同时构造 completed、failed、pending、running，断言仅前两种被统计）。
- [ ] `deletable_count` 遵循渠道和错误筛选（验证：分别请求全部、指定 `channel_id`、`errors_only=true` 以及组合条件，逐一核对数量）。
- [ ] 空筛选结果返回 `deletable_count=0`（验证：请求不存在的渠道或无匹配错误日志，响应为 0 且页面范围删除不可执行）。
- [ ] 批量删除接口契约保持不变（验证：请求仍发送至 `/api/runs/bulk-delete`，请求体只有 ID 集合，响应继续处理 `deleted`、`missing`、`failed`）。
- [ ] 列表加载未新增逐行详情请求（验证：浏览器网络记录中首屏 `/api/runs/*/results` 请求数仍为 0）。

## 集成与回归

- [ ] 渠道、错误筛选、分页和删除状态联动（验证：从第 2 页切换筛选回到第 1 页；删除后页码、总数、可见行和按钮数量同步更新）。
- [ ] 删除成功后相关查询刷新（验证：巡检列表、普通运行列表和报告查询被失效，页面不残留已删除记录或过期选择）。
- [ ] 单行删除、展开详情、查看详情和取消运行保持原行为（验证：逐项操作并观察成功结果，控制台无异常）。
- [ ] 普通检测任务删除入口未改变（验证：普通任务卡片的选择、删除确认和批量删除行为与变更前一致）。
- [ ] 无障碍状态完整（验证：两个删除按钮有可辨识名称；错误筛选保留 `aria-pressed`；禁用原因可通过键盘聚焦提示区域获知）。

## 端到端场景

- [ ] 窄窗口完整操作流程（验证：窄视口打开 `/runs` -> 观察工具栏换行且不裁切 -> 勾选已结束日志 -> 打开确认 -> 删除 -> 观察列表和数量刷新）。
- [ ] 跨页当前范围删除流程（验证：准备超过 100 条混合状态日志 -> 观察按钮显示全部筛选范围可删除数量 -> 确认删除 -> 检查所有已结束匹配日志被删除，pending/running 保留）。
